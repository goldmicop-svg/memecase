# MEME CASE — апгрейдер мем-скинов

Flask-приложение: кейсы, апгрейдер с шансом, инвентарь, профиль,
регистрация и демо-покупка монет. Игровая логика (баланс, RNG выпадения,
шанс апгрейда) считается на сервере (`app.py`), фронтенд —
`templates/index.html`.

## Структура

```
meme_case/
├── app.py                # сервер + игровая логика (Flask, Python)
├── templates/
│   └── index.html        # HTML/CSS/JS страницы
├── static/
│   ├── characters/       # 26 добавленных персонажей с фото
│   └── uploads/          # аватары, загруженные игроками (создаётся сам)
├── meme_case.db          # локальная база аккаунтов (создаётся сам)
├── requirements.txt
└── README.md
```

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

Открой в браузере: http://127.0.0.1:5000

## Важно

- «💰 Пополнить баланс» — это **демо-начисление** монет на сервере.
  Реального платёжного шлюза (приёма настоящих денег) в проекте нет
  и не подключался.
- При первом открытии создайте аккаунт или войдите. Пароли сохраняются
  только в хешированном виде в локальном SQLite-файле `meme_case.db`.
- Никнейм `lorren` получает роль администратора. В профиле для него
  открывается админ-панель: выбрать игрока, выдать монеты, выдать одного
  из новых персонажей, заблокировать или разблокировать аккаунт.
- Аватар загружается через профиль. Допустимы PNG, JPG, WEBP и GIF до 2 МБ.
- Игровые данные хранятся в памяти процесса (`GAME_DB`), поэтому баланс и
  инвентарь сбросятся при перезапуске. Аккаунты, аватары и баны сохраняются.
- Настройка «Телефон / ПК» в разделе ⚙️ Настройки переключает
  раскладку интерфейса.
- При смене вкладки содержимое плавно сдвигается в сторону новой вкладки.
